# Goal
Always build the lates versions of each package instead of tracking hind releases.

# Context
Each version available to build from needs to be maintained and tested.

The `pkg/build/release/versions.go` is clunky.

# Constraints and open questions
should we
- provide a registry of the available versions for each package that we support?
- let users pass in arbitrary versions?
- let users provide a config file?
- still track releases? or only track the latest tested versions
- provide historical release data if we only have latest?
- pass version flags via the build command to offer custom versions?
